# Diabetes Prediction Model

A Machine Learning web application that predicts the likelihood of diabetes based on medical input features. Built using Python, Scikit-learn, Pandas, NumPy, and Streamlit.

## Key Features

- **Diabetes Prediction:** Predicts the likelihood of diabetes using a trained Machine Learning model.
- **Medical Input:** Accepts health-related information such as glucose level, blood pressure, BMI, age, and insulin.
- **SVM Algorithm:** Uses Support Vector Machine (SVM) for classification.
- **Data Preprocessing:** Uses StandardScaler for feature standardization.
- **Interactive Web Interface:** Provides a simple and user-friendly interface using Streamlit.
- **Real-Time Predictions:** Displays prediction results based on user-provided inputs.
